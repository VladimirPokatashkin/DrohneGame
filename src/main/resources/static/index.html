1. Литералы и типы данных
КонструкцияОписание
123 / x1AFЦелые числа (десятичные или шестнадцатеричные с префиксом x).
shinri / usoЛогические константы Истина (1) и Ложь (0) соответственно.
seisu a = 8;Объявление целой переменной со знаком.
ronri b = shinri;Объявление логической переменной.
rippotai c = {x, y, z, obs};Ячейка пространства (координаты X, Y, Z и флаг препятствия). Доступ к полю: c=>field.
hairetsu arr = {d1, d2};Массив с заданными размерностями. Доступ: arr[i1, i2].

КатегорияОператоры
Арифметика+, -, присваивание =

3. Управляющие конструкции
СинтаксисОписание
sorenara <cond> kido <body> shushi;Условный оператор. Выполняет тело, если условие истинно.
shuki i = s1 : s2 kido <body> shushi;Цикл. Выполняет тело, меняя i от s1 до s2.
4. Функции
СинтаксисОписание

name(arg1, arg2);Вызов функции (может вызывать функцию, объявленную ниже по коду).
5. Управление дроном
КомандаОписание
^_^ / v_vДвижение вверх (Z+) / вниз (Z-). Столкновение с препятствием ломает дрона.
<_< / >_>Движение влево (X-) / вправо (X+).
o_o / ~_~Движение вперед (Y-) / назад (Y+).
^_0, v_0, <_0, >_0, o_0, ~_0Измерение расстояния до ближайшего препятствия в указанном направлении.
*_*Получение текущей ячейки местоположения дрона (возвращает rippotai).
{ op1; op2; ... }Последовательность операторов.
>_<Оператор прерывания внутри блока {...}, если в соседней ячейке обнаружено препятствие.

Все предложения языка должны завершаться символом ;. Язык чувствителен к регистру. Типизация строгая, есть неявное приведение целых чисел к логическим константам и наоборот.
