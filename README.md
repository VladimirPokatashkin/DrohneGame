# 🛸 DrohneGame — 3D Drone Simulator & Abobalang Interpreter

Веб-симулятор трехмерного лабиринта и интерпретатор предметно-ориентированного языка (DSL) **Abobalang**. Проект предназначен для написания программ автономной навигации квадрокоптера в 3D-пространстве, его отладки и пошаговой визуализации полёта.

---

## 🛠 Технологический стек

* **Backend:** Java 22+, Spring Boot 3.3.0, Maven
* **Parser Generator:** JFlex 1.9.1 (лексический анализ) & Java CUP 11b (синтаксический анализ)
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS, Event-driven Step Animation)

---

## 🚀 Основные возможности

* **Полный цикл интерпретации DSL:**
* Лексический анализ (Lexer) и синтаксический анализ с построением AST-дерева (Parser).
* Семантический анализ типов и проверка областей видимости переменных/функций.
* Выполнение AST в изоляции от графической оболочки с подсчетом пошаговых метрик.


* **Интерактивный UI с визуализатором:**
* Послойная визуализация 3D-лабиринта по оси **Z**.
* Пошаговая анимация полета с плавной регулировкой скорости.
* Визуальные эффекты сканирования пространственных лучей дрона и подсветка аварий (`crashed`).


* **Детализированный вывод ошибок:** Вывод точных координат и сообщений о лексических (`lexical error`), синтаксических (`syntax error`), семантических (`semantic error`) и рантайм-ошибках (`crashed`).

## 📖 Справочник по языку Abobalang

### 1. Типы данных и литералы

| Синтаксис | Описание |
| --- | --- |
| `123` / `x1A_F` | Десятичные и шестнадцатеричные (с префиксом `x`) целые числа. |
| `shinri` / `uso` | Логические литералы Истина (`1`) и Ложь (`0`). |
| `seisu a = 10;` | Целая переменная со знаком. |
| `ronri b = shinri;` | Логическая переменная. |
| `rippotai c = {x, y, z, obs};` | Трехмерная ячейка пространства. Доступ к полю: `c=>x`, `c=>y`, `c=>z`. |
| `hairetsu arr = {8, 5, 5};` | Массив пространственных измерений. Доступ: `arr[i, j, k]`. |

### 2. Операторы и служебные функции

* **Арифметика:** `+`, `-`, присваивание `=`.
* **Логика:** `~` (NOT), `^` (AND), `v` (OR).
* **Сравнения:** `<`, `>`.
* **Служебные:** `jigen <arr>` (получение размерности массива),
  `ruikei {t1 t2}` (сравнение типов),
  `kowasu;` (прекращение выполнения цикла на текущей итерации),
  `modoru` (возврат из функции).

### 3. Управляющие конструкции и функции

* **Условие:** `sorenara <condition> kido <statements> shushi;`
* **Цикл:** `shuki i = start : end kido <statements> shushi;`
* **Функция:** `[type] kansu name([params]) kido <statements> shushi;`

### 4. Управление дроном

| Команда | Описание |
| --- | --- |
| `^_^` / `v_v` | Движение вверх ($Z+$) / вниз ($Z-$). Столкновение с препятствием ломает дрона. |
| `<_<` / `>_>` | Движение влево ($X-$) / вправо ($X+$). |
| `o_o` / `~_~` | Движение вперед ($Y-$) / назад ($Y+$). |
| `^_0`, `v_0`, `<_0`, `>_0`, `o_0`, `~_0` | Измерение расстояния до ближайшей стены в указанном направлении. |
| `*_*` | Возвращает текущее положение дрона в виде `rippotai`. |
| `{ op1; op2; ... }` | Блок последовательного выполнения команд. |
| `>_<` | Оператор прерывания внутри блока `{...}`, если в соседней ячейке найдена стена. |

## 💻 Сборка и запуск

### Требования

* JDK 22 или новее
* Apache Maven 3.8+

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/DrohneGame.git
cd DrohneGame

```

### 2. Генерация лексера и парсера

Генерация Java-классов `Lexer` и `Parser` из спецификаций JFlex (`.flex`) и CUP (`.cup`):

```bash
mvn generate-sources

```

### 3. Запуск приложения

```bash
mvn spring-boot:run

```

После запуска откройте браузер и перейдите по адресу:
`http://localhost:8080/index.html`
